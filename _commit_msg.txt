fix: 更正 AI剧情 评分的错误结论（根因是 recordUuid 传错记录）

★ 结论更正
此前在 README / docs / 两处代码注释里都写过：
  「AI剧情评分必须由浏览器建立对答会话，纯 HTTP 调 evaluate/stream
    返回『会话不存在』，因此无法自动化 → 需人工」
该结论是错的。

真实原因是参数传错：evaluate/stream 的 recordUuid 必须传【外层记录】，
章节记录单独放在 chapterRecordUuid。判据来自对话页
TaskChainChat.startEvaluate()（chunk 1247）：它用的是 currentRecordUuid。

对照实测（同一接口、同一条记录）：
  传外层记录 → 「任务未提交，无法开始评估」（真实业务状态）
  传章节记录 → 「会话不存在」（参数对不上）
即「会话不存在」只是参数错误的症状，与"是否有浏览器会话"无关。
