② 章节任务点原项目已有

  • 课程列表 / 多选勾选即同步，无需先保存配置
  • 视频 — 进度上报 + 心跳自动 播放倍速 1.0–2.0，并发章节数可调
  • 文档 / 阅读自动
  • 音频自动
  • 作业 / 测验 — 题库作答审批后提交 逐题作答 → 覆盖率校验 → 提交
  • 实时进度监控课程进度 / 章节统计 / 任务状态，支持「优雅停止」：不再开新章节，当前章节收尾后退出
  • 未开放章节策略notopen_action = retry | continue

③ 「任务」模块 本项目新增

  • 两套互不相通的系统 mooc1 章节任务点 vs task.chaoxing.com「任务」标签 —— 原项目完全没有后者，本项目补了整层：任务点发现 → 类型适配注册表 → 12 个处理器
  • 只读盘点 预览摊开每个任务点的类型、进度、完成条件、能否自动完成，以及不能的话为什么（需先备材料 / 暂未支持 / 学习窗口未开放）
  • 类型适配注册表planType → AdapterSpec(handler, status, label, note)，14 种类型
  • 诚实降级effective_status()：注册表声明的是目标状态，处理器没写就自动降级为「尚未实现」，界面绝不虚报全能
  • 命令行--fanya-tasks（只读盘点）· --fanya-execute（执行）· --fanya-plans 1,2

④ 12 个任务处理器能力矩阵 · 按实测状态标注

  • 视频（planType 10）已实测 任务引擎自有播放页 videoStudy/learnPage，上报 videoDataLog 一次到位，isFinish 立即翻转
  • 文档（11）已实测documentStudy/readEnd
  • 章节 / 知识点（8 / 1）已实测复用章节任务点流程
  • 作业（4）审批后提交 mooc2 课程作业，需单独适配器（knowledgeid=0 不在章节里）
  • 主题讨论（14）已实测 AI 生成回复并提交；提交前先检测是否已回复，避免重复
  • 音频（22）未验证与视频同构；本账号无样本
  • 自测 / 测验（17 / 5）默认只暂存 题库作答；须显式开「考试交卷」才提交。过期样本无法补完成
  • 分组任务（18）默认不提交 提交会覆盖全组已有内容，故默认拒绝覆盖；完成取决于评分 ≥60
  • 问卷（6）· 线下课堂（20）· AI课堂（10042）需人工 走超星 OA 表单 / 教师侧记录 / 第三方棱镜课堂，客户端不上报泛雅

⑤ AI 实践 5 个子模式

  • 代码实践（mode 4）实测 76 分 AI 生成代码 → 自测运行校验 → 建卷交卷 → SSE 出分
  • 思维阶梯（mode 2）实测 85 分 拆题 → 8 轮逐题作答（含多选）→ 交卷 → 结题报告出分
  • 上传作品（mode 1）实测 100 分 生成作品 → 渲染 PNG → 传网盘 → 挂附件 → 交卷 → AI 评分；
    交卷前回读校验附件确实挂上，挂不上则中止（不会交空记录）
  • 情景对话（mode 0）未真机验证 生成场景 → 多轮对话 → 交卷 → 评估出分；带中止保护
  • AI剧情（mode 7）链路已打通 章节 + 节点结构（4 段对话 + 1 个上传报告）。交卷不可逆（部分课程 enableReset=false），故不代提交，需你确认

⑥ 安全护栏与可靠性本项目新增

  • 生成 → 审批 → 提交 凡会写进你账号的内容（作业答案、讨论回复、AI 实践作答）默认只生成、不提交，在「待审批」面板摊开，你逐条核对过才真正提交。
    动机很实际：早期版本直接把内容交上去过，出过事故。
  • 拒答识别硬防线 题库偶尔把「我看不到题目，请提供文字描述」当成答案返回；这类元回复会被识别并按「未命中」处理，绝不会写进作业。全部未命中时直接拒绝提交。
  • 修掉过的静默失败 「报告成功、其实做错」比崩溃更糟，因为你会信任它。已修：判断题必须发 true/false（发「对/错」服务端拒绝整份提交）；上传作品附件载荷是扁平数组而非卡片结构。
  • 单元测试tests/test_parsers.py 解析层 24 个用例 + tools/smoke_test.py 冒烟 + GitHub Actions
  • 通知PushPlus / Bark / 钉钉 / 飞书 / 企业微信

⑦ 题库与 AI 能力可插拔

  • 题库提供商言溪题库 · LIKE 知识库 · AI 大模型 · 硅基流动 · TikuAdapter · 不使用
  • 覆盖率策略cover_rate 低于阈值不提交；min_interval_seconds 限速
  • AI 配置endpoint / key / model / 单卷最大并发题目数
  • OCR独立 OCR 提供商配置（图片题）
  • 内容生成器ContentGenerator：讨论回复、AI 实践作答等文本统一走这里

已知边界（任何逆向实现的工具都会随平台改版静默失效）：
主题讨论的实际发帖 / 测验的正式交卷 / 上传作品的多附件 / 情景对话 —— 未实测或半自动；
作业与测验的自动重做不支持（平台重做是自有 UI 流程，请求格式未探明）；
解析层有 24 个单元测试，接口层没有自动化测试；部分题目原文要求「用自己的话整理、禁止复制 AI 输出」，工具默认只出草稿。
